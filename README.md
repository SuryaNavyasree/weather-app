# 🌦️ Elegant Weather App

A modern and elegant weather forecast website built using HTML, CSS, and JavaScript.

## 🚀 Features

- Search weather by city
- Live temperature data
- Humidity and wind speed
- Elegant glassmorphism UI
- Responsive design
- Weather icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
